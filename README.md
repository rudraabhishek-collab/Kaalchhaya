# Kaalchhaya

Kaalchhaya (Sanskrit: "shadow of time") is a time-slider radar that maps the lifecycle of trade rules and HS (Harmonized System) codes — showing when they expire, change, or get renumbered — so importers, exporters, and customs teams can see exactly what their compliance landscape looks like at any point in time. Drag the slider to any date and the radar highlights which rules are live, which are sunsetting, and which codes have been renumbered under that effective window.

## Quick start

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Run all tests (single pass)
npm test

# Run property-based tests only
npm run test:props

# Type-check without emitting
npm run typecheck

# Lint
npm run lint
```
